# 💼 Personal Portfolio Website

A modern and responsive personal portfolio website built with React and Vite. The project showcases my education, skills, projects, experience, and contact information through a clean and user-friendly interface.

## 🚀 Live Demo

🔗 https://your-portfolio-link

---

## ✨ Features

- Responsive design
- Light and modern portfolio theme
- One-page personal layout
- Skills section with technology badges
- Projects showcase
- Experience and education timeline
- Contact section with CV download
- Smooth, polished UI styling
- Mobile-friendly layout

---

## 🛠️ Technologies

- React
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- Responsive design
